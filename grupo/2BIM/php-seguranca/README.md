# 🔐 Pesquisa - Segurança em Aplicações Web com PHP

Pesquisa acadêmica desenvolvida sobre os principais conceitos e mecanismos de segurança utilizados em aplicações web desenvolvidas em PHP.

---

## 📌 Sobre o Projeto

Este trabalho apresenta um estudo sobre Segurança da Informação aplicada ao desenvolvimento web, abordando conceitos essenciais como criptografia, funções de hash, codificação, proteção de senhas e prevenção contra os principais ataques virtuais.

Também são exploradas as principais funções nativas do PHP relacionadas à segurança, destacando suas aplicações práticas e a importância da adoção de boas práticas durante o desenvolvimento de sistemas.

---

## 📚 Conteúdo da Pesquisa

A pesquisa aborda os seguintes temas:

- Segurança em aplicações Web
- Criptografia, Hash e Codificação
- Funções de Hash no PHP
- Funções de Codificação
- Criptografia utilizando OpenSSL
- Proteção de Senhas
- Proteção contra ataques (SQL Injection, XSS e CSRF)
- Aplicações práticas
- Boas práticas de segurança
- Conclusão
