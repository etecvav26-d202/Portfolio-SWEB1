# 💊 Farmácia VAV

Sistema web desenvolvido em PHP para gerenciamento de uma farmácia fictícia, criado como projeto acadêmico.

## 📌 Sobre o Projeto

O **Farmácia VAV** tem como objetivo simular o funcionamento básico de um sistema farmacêutico, permitindo o gerenciamento de informações de forma simples e organizada, mostrando os produtos cadastrados pela própria fármacia e seção onde permite cadastrar o produto.

O projeto foi desenvolvido utilizando tecnologias web fundamentais, com foco em aprendizado prático de desenvolvimento back-end e integração com banco de dados.

---

## 🛠️ Tecnologias Utilizadas

* PHP
* MySQL
* HTML5
* CSS3
* JavaScript
* phpMyAdmin
